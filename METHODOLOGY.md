# Recursive Foundational Inquiry (RFI)

Рабочий синтез методов, новизна которого не установлена.

Цикл: определить утверждение и область → выявить необходимые условия → построить формальную модель → искать контрмодели → проверить необходимость и достаточность отдельно → сравнить с литературой → проверить самоприменение, если оно типизировано → зафиксировать пределы.

Не считать отсутствие контрпримера доказательством. Не вводить сущность только из последовательности отрицаний. Не смешивать логическую необходимость с эмпирической регулярностью. Останавливать углубление при отсутствии определённой операции или проверяемого вопроса.
