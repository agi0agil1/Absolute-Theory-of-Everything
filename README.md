# Foundations of Determinacy

**Основания определённости** — открытая метатеоретическая исследовательская программа условий различения, воспроизводимости и знания.

Первый научный вопрос: при каких условиях повторное различение считается воспроизводством того же содержания?

Метод: рекурсивное исследование оснований, формализация, контрмодели, проверка пределов и самоприменения. Универсальность не предполагается заранее.
