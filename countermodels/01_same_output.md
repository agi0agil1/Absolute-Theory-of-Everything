# Контрмодель: одинаковый результат, разные критерии

X={0,1,2}. δ(x)=1 при x≥1, иначе 0. ε(x)=1 при x≥2, иначе 0. Для x=2 результаты совпадают, но для x=1 различаются.

Следствие: совпадение одной метки не гарантирует эквивалентность операций на домене. Это не доказывает необходимость хранения всех условий: при критерии тождества только по метке совпадения достаточно. Требуется явно определить, что именно воспроизводится.
